# ResQ-Vision

## 🚨 Autonomous Multi-Modal Accident Triage & Emergency Response System

ResQ-Vision is an emergency response and incident management platform designed to streamline accident detection, emergency reporting, information sharing, and response coordination.

**🌐 Live Website:** https://resqvisionportal.netlify.app/

---

## 🚑 Project Overview

ResQ-Vision is a prototype emergency response orchestration platform designed to reduce delays in the road emergency response chain.

The system demonstrates how accident information can be detected, analyzed, communicated, and coordinated between emergency responders, ambulances, hospitals, and traffic management systems.

### Core capabilities

1. Accident detection and incident monitoring
2. Crash severity assessment
3. Emergency dispatch coordination
4. Ambulance response management
5. Hospital preparedness and resource coordination
6. Emergency traffic corridor monitoring
7. Real-time incident telemetry

---

## 🛠️ Technology Stack

- **Frontend:** React + Vite
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Icons:** Lucide React
- **Maps & Location:** Google Maps
- **Visualization:** SVG / HTML5 Canvas
- **Audio:** Web Audio API
- **Deployment:** Netlify
